# Support for DexPresenter

DexPresenter is a personal project provided "as-is" under the GPLv3 license.

### Critical Expectations
* **No Guaranteed Support:** There is no formal support desk or guaranteed response time for this project.
* **Delayed Responses:** Responses to issues may be delayed by several weeks, or may not receive a response at all depending on current time constraints.
* **Prioritization:** Development is focused on the author's own use cases. Issues that do not align with the project's current direction will be closed without action.

### How to use this repository
1. **Search First:** Before opening an issue, search existing closed and open issues to see if your question has been addressed.
2. **Bug Reports:** If you find a technical fault, [open an issue](https://github.com/guHe330/DexPresenter/issues) with a clear description and steps to reproduce.
3. **No Feature Requests:** At this stage, the feature set is considered stable for the author's needs.

**If you require immediate support or specific features, you are encouraged to fork the repository as permitted by the GPLv3 license.**
