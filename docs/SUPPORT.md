# Support for DexPresenter

DexPresenter is a personal project provided "as-is" under the GPLv3 license. There is no support desk and no guaranteed response time. One person maintains it in their spare time.

## What to expect

- Responses may be slow, or may not come at all. Issues are read when there is time.
- Development follows the author's own use cases. Requests that don't fit the project's direction may be closed without action.
- Only the latest release is maintained. There are no backports.

## Where to go

| I want to… | Go to |
| ---------- | ----- |
| Report a bug | [Open a bug report](https://github.com/guHe330/DexPresenter/issues/new?template=bug_report.yml) |
| Report how it behaves on my monitors | [Multi-monitor / DPI test report](https://github.com/guHe330/DexPresenter/issues/new?template=multi_monitor_report.yml), the most useful kind of report right now |
| Suggest a feature | [Open a feature request](https://github.com/guHe330/DexPresenter/issues/new?template=feature_request.yml) |
| Report a security problem | [Privately, via a security advisory](https://github.com/guHe330/DexPresenter/security/advisories/new), never a public issue. See [SECURITY.md](../SECURITY.md) |
| Learn how a feature works | [FEATURES.md](FEATURES.md) and [CONFIGURATION.md](CONFIGURATION.md) |
| See what changed | [CHANGELOG.md](CHANGELOG.md) |
| Contribute code | [CONTRIBUTING.md](CONTRIBUTING.md) |

Check [open and closed issues](https://github.com/guHe330/DexPresenter/issues?q=is%3Aissue) before opening a new one.

If you need guaranteed support or a specific feature, fork it. The GPLv3 lets you make the change yourself instead of waiting for me.
